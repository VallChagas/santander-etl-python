// The problem

Data needs a dependable route.

Raw records are only a starting point. To make them useful, a workflow needs to gather the right users, enrich their information, and save the result in a format other tools can read.

This project keeps those responsibilities distinct. Python reads user IDs from a CSV, retrieves sample records from a simulated API, and transforms each record with a personalized message.

The transformed users are written to a JSON file, making each step easy to follow, run again, and extend. The website demo mirrors that flow locally in your browser; it does not connect to the project's API.

// Architecture

Three stages. One pipeline.

Each stage has one clear responsibility, from the first user ID to the final JSON file.

01 / INPUT

Extract

Read user IDs from the CSV and fetch each record from the simulated API.

# src/extract.py user_ids = read_user_ids()
users = [
  extract_user(uid)
  for uid in user_ids
]
CSV + APIHTTP / JSON
02 / PROCESS

Transform

Add a personalized message to every user while keeping the workflow easy to read.

# src/transform.py user["message"] = (
  f"Hello, {name}!"
  " Glad you're here."
)
return user
Per-user mappingPython
03 / OUTPUT

Load

Serialize the transformed records and save them as a readable JSON output file.

# data/users_transformed.json {
  "id": 4,
  "name": "Sample User",
  "message": "Hello!"
}
